How to Rebuild & Switch

One flake command applies system packages, services, Home Manager, and all symlinked dotfiles together.

  1. 1. Edit Source

    Modify configuration.nix, home.nix, or dotfiles/* under /etc/nixos.

  2. 2. Rebuild Flake

    Switch both NixOS 26.05 and Home Manager atomically with rollback support.

  3. 3. Bump Inputs

    Run sudo nix flake update or update just zen-browser when needed.

Primary workstation rebuild (NixOS + Home Manager) 
cd /etc/nixos && sudo nixos-rebuild switch --flake .#nixos
  1. 1. Place k3s Token

    Ensure the cluster join token is stored securely at /etc/k3s-token.

  2. 2. Apply Worker Flake

    Configures static IP 192.168.0.11/24, firewall rules, and k3s agent.

  3. 3. Verify Node

    Connects to control plane 192.168.0.10:6443 with kubectl ready.

Homelab k3s worker node rebuild 
cd /etc/nixos && sudo nixos-rebuild switch --flake ./asus-worker#asus-worker

asus-worker — Homelab k3s Agent Node

Minimal, reproducible NixOS 26.05 server joining the homelab Kubernetes cluster with declarative static networking and locked-down firewall rules.

NixOS 26.05 k3s agent 192.168.0.11/24 enp2s0 static

Kubernetes (k3s)

  • Role: agent (--node-name=asus-worker)
  • Control plane: https://192.168.0.10:6443
  • Cluster token loaded via /etc/k3s-token
  • kubectl pre-installed for diagnostics

Static Networking

  • Interface: enp2s0 (DHCP disabled)
  • Static IPv4: 192.168.0.11/24
  • Gateway: 192.168.0.1
  • DNS: 192.168.0.10, 1.1.1.1

Firewall & SSH

  • Firewall enabled by default
  • TCP allowed: 22 (SSH), 10250 (kubelet)
  • UDP allowed: 8472 (Flannel VXLAN)
  • OpenSSH with PermitRootLogin = "no"

Shell & Utilities

  • Zsh with autosuggestions & syntax highlighting
  • vim, git, curl, wget
  • btop, htop, bat, fastfetch
  • Experimental nix-command & flakes enabled
Clean Separation

configuration.nix vs home.nix

One guiding question: "Does this affect every user on the machine, or just my account?"

System-wide

/etc/nixos/configuration.nix

  • Hostname, timezone (Australia/Sydney) & locale
  • System services: Tailscale, OpenSSH, PipeWire, CUPS, GDM
  • Bootloader, CS8409 kernel module & firewall rules
  • System packages (environment.systemPackages)
  • rclone systemd timers & weekly Nix garbage collection
User-level

/etc/nixos/home.nix

  • Git identity (programs.git) & user CLI tools
  • Zsh aliases, autosuggestions & Starship integration
  • Ghostty terminal theme, opacity & Nerd Font
  • Neovim as default editor (vi / vim aliases)
  • Recursive symlinks for hypr, waybar, rofi, wofi, wlogout

Golden Rule: Never edit Home Manager–managed files directly inside ~/.config/ — they are read-only symlinks into the Nix store. Always edit under /etc/nixos/ and run nixos-rebuild switch.
